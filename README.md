# Proyecto NutriVida
Proyecto inicial equipo 7 informática 2026

------------


Una aplicacion web para ayudar a conseguir resetas en base una pauta nutricional.

------------

## Funcionalidades planeadas
-  Búsqueda de recetas saludables adaptadas a las pautas nutricionales de cada usuario. (hecho)
- Apartado especial para la entrega de recetas equilibradas aptas para niños, como postres o recetas entretenidas para fomentar el consumo de alimentos saludables.
- Una lista de recetas para un máximo de 5 días . (hecho)

------------


## Instrucciones de uso
#### Instalacion
-  (recomendado) crear un amviente virtual
- instalar las dependencias de requirements.txt

#### Uso
1. Entrar en la pagina y hacer click en el boton de empezar
2. Rellenar el formulario con las preferencias nutritivas, todos los campos son obligatorios (se recomiendan rangos amplios)
3. Ver las recetas precionando los botenes correspondeintes (y desfrutar de la vida saludable :D)
